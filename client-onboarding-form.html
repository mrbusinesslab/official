Firebase 規則設定

前往 Firebase Console 依下方步驟貼上規則，讓客戶可以填寫自己的表單，但無法看到他人資料。

Step 1 — Firestore Database Rules
Firestore Database → 規則 → 貼上並發布：
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /projects/{projectId} {
      // 任何人持有 projectId 即可讀（客戶憑連結填寫）
      allow read: if true;
      // 允許建立（管理員用 client SDK 建立）
      allow create: if true;
      // 允許更新（含客戶編輯已填內容後再次送出）
      allow update: if true;
      // 允許刪除（僅後台管理員操作介面會呼叫，客戶端不會用到）
      allow delete: if true;
    }
  }
}
提醒：此規則為「憑連結即可存取」邏輯，未做帳號驗證。客戶只要拿到專屬連結即可讀寫該筆專案，但無法看到其他客戶的資料；刪除功能僅在管理後台介面提供按鈕，客戶端表單不會呼叫刪除。
✓ 不需要設定 Storage

此版本圖片以壓縮後的 base64 格式直接存入 Firestore，完全不需要啟用 Firebase Storage，Firebase 免費方案（Spark）即可使用。

每張圖片壓縮後約 100–200KB，Firestore 免費方案每天提供 1GB 讀寫，一般業務量完全足夠。
